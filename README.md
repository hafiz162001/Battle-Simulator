# ⚔️ Battle Simulator 3D (Desert & Urban Warz)

Simulator pertempuran massal 3D berkecepatan tinggi yang dibangun menggunakan **Godot Engine 4.3 (Forward+)**.

## 🌟 Fitur Utama
- **Arena Perkotaan Modern (Urban Metropolis)**: Lengkap dengan gedung pencakar langit, jalan aspal PBR, marka jalan, sistem pencahayaan fotorealistik (SDFGI, SSAO, SSR, ACES Tonemapping, dan TAA).
- **Gaya Bertarung Realistis**:
  - Kombo serangan 3-hit dinamis (*lead strike*, *cleave*, dan *finisher*).
  - *Active Shield Block & Parry* dengan reduksi kerusakan 75%.
  - *Tactical Footwork & Circle-Strafing* serta *Kiting* untuk pemanah.
  - Senapan serbu 3-round burst untuk Commando Gunner.
  - Gaya tinju *peek-a-boo* Mike Tyson dan gempa bumi Titan.
  - Reaksi benturan 3D (*directional flinch*) dan fisika ragdoll balistik.
- **Sistem Ultimate Skill**: Tiap kelas memiliki skill ultimate unik dengan pengisian energi.
- **Super Ultimate (Kereta Cepat IKN Whoosh & Sayap Garuda)**:
  - Video cutscene sinematik sebelum serangan.
  - Kereta Cepat IKN Garuda Megastructure menerjang melintasi arena dan menabrak lawan-lawan ke udara.
- **Kustomisasi Prajurit**: Mendukung pengimporan model 3D glTF/GLB kustom (misal: Jokowi, Elon Musk, dll).

## 🚀 Cara Menjalankan
Jalankan file batch:
```bat
run_desktop_game.bat
```
Atau buka folder `desktop_simulator` melalui Godot Engine 4.3.
